# 📖 Agenda Telefônica

Aplicação simples e intuitiva para gerenciamento de contatos telefônicos desenvolvida com HTML5, CSS3 e JavaScript.

## 🚀 Funcionalidades
- Cadastro de novos contatos com validação de campos.
- Listagem dinâmica e contagem em tempo real de contatos salvos.
- Interface responsiva e moderna com fontes do Google Fonts e ícones do FontAwesome.

## 💻 Tecnologias
- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
