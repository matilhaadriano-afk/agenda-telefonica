## 🧠 1. Aura AI — Chatbot com Memória & Banco de Dados (Diretório `/chatbot-ia`)
Assistente inteligente com memória persistente de longo prazo usando **SQLite**, **Python (Flask)**, **HTML5/CSS3/JavaScript** e integração com **Google Gemini (2.5 Flash)**.

### Destaques:
- **Administração de Dados:** Extrai e memoriza preferências, tarefas e dados pessoais do usuário em banco relacional SQLite.
- **Frontend Futurista:** Design em Dark Mode Glassmorphism, renderização de Markdown, painel visual de gerenciamento de memórias e busca dinâmica.
- **Modo Híbrido:** Executa com a API do Gemini ou modo local inteligente com banco de dados.

Consulte o arquivo [`chatbot-ia/README.md`](chatbot-ia/README.md) para instruções detalhadas de inicialização.

## 📖 2. Agenda Telefônica
Aplicação simples e intuitiva para gerenciamento de contatos telefônicos na raiz do projeto.

### Funcionalidades:
- Cadastro de novos contatos com validação de campos.
- Listagem dinâmica e contagem em tempo real de contatos salvos.
- Interface responsiva com fontes do Google Fonts e ícones do FontAwesome.

### Tecnologias:
- **HTML5**, **CSS3** e **JavaScript (Vanilla)**
